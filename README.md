# GroundingPI and GroundAnything project pages

- [GroundingPI](https://groundingpi.github.io/) · [Paper](https://arxiv.org/abs/2609.39601)
- [GroundAnything](https://groundingpi.github.io/groundanything/) · [Paper](https://arxiv.org/abs/2609.39600)

Static GitHub Pages site served from the root of `main`; no build step is needed.

`index.html` is GroundingPI, and `groundanything/index.html` is GroundAnything. Each page has its own `assets` directory. The original no-logo opening videos are complete. The full demonstration videos below the fold load on demand.

Both pages support English and Chinese through the top-right language switch. The selected language is retained between pages. Chart artwork, model names, numerical values, and BibTeX remain unchanged when switching languages.

Physical intelligence, data efficiency, scaling, data composition, decoding, draft generation, and inference optimization figures support interactive exploration. Numerical details are expandable, and side-by-side figures stack on smaller screens. The Ablation Study sections are omitted.

The interactive radar diagrams preserve the published paper artwork and aggregate values. Individual benchmark results in `assets/benchmarks.json` are transcribed from the published arXiv v1 Appendix tables. Each table links to its source. Local evaluations and published external references are separate views. Missing and protocol-uncertain entries do not enter rankings; no missing values are reconstructed.
